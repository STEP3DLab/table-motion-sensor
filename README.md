# Датчик движения стола

Статический сайт-инструкция для устройства на Arduino Uno и акселерометре Амперка AMP-B041.

## Открыть на компьютере

Распакуйте архив целиком и откройте `index.html` в современном браузере. Интернет и установка дополнительных программ не требуются. Сохраняйте рядом папки `assets` и `downloads`.

## Разместить на GitHub Pages

Поместите содержимое этого архива в каталог, который публикует GitHub Pages: `index.html`, `styles.css`, `app.js`, `.nojekyll`, `assets/` и `downloads/`. Все ссылки относительные, поэтому сайт работает и в корне домена, и в каталоге репозитория. Сборка и серверная часть не нужны.

## Структура

- `index.html` — страницы и основное содержание.
- `styles.css` — оформление и мобильная версия.
- `app.js` — карточки компонентов, метки, шаги сборки и переходы.
- `assets/` — иллюстрации, модели компонентов на изображениях и схема подключения.
- `downloads/` — файлы Arduino, инструкция PDF, модели STEP/STL и архивы.

Программа находится отдельно в `downloads/TableMotion.ino` и в архиве `downloads/TableMotion.zip`. Для Arduino IDE удобнее архив: он сохраняет папку `TableMotion` с одноимённым скетчем.

3D-изображения электроники служат для объяснения расположения компонентов. Посадку реальных деталей и чувствительность прибора необходимо проверить при сборке.
